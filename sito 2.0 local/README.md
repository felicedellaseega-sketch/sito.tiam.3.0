# Sito Tiam Shanghai 2.0 Local

Sito web completo per Tiam Shanghai con tutte le immagini e i video inclusi.

## 📁 Struttura del progetto

- `index.html` - File HTML principale
- `styles.css` - File CSS con tutti gli stili
- `scripts.js` - File JavaScript per il cursore personalizzato
- `sito definitivo/` - Cartella con tutte le immagini e i video

## 🚀 Come visualizzare il sito

### Metodo 1: Server locale (consigliato)

1. Apri **Terminale**
2. Vai nella cartella del sito:
   ```bash
   cd ~/Desktop/"sito 2.0 local"
   ```
3. Avvia un server locale:
   ```bash
   python3 -m http.server 8000
   ```
4. Apri il browser e vai su:
   ```
   http://localhost:8000
   ```

### Metodo 2: Aprire direttamente il file

1. Vai nella cartella `sito 2.0 local` sul Desktop
2. Fai doppio clic su `index.html`
3. Il sito si aprirà nel browser predefinito

**Nota:** Alcuni browser potrebbero bloccare il caricamento delle immagini quando si apre un file HTML direttamente. In quel caso, usa il Metodo 1 (server locale).
